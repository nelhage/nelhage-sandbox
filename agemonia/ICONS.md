# Icon Glossary

Canonical names for the icons used in the Agemonia *Rules Reference Book*.

**Notation:** transcribe an icon as its canonical name in square brackets, exactly as
spelled in the `Notation` column — e.g. `roll a number of [Action Die] equal to...`,
`spend 1 [Stamina]`, `[Might] 4`. Names are Title Case.

Where the book itself labels an icon (chiefly the back-cover legend on **PDF p68**, and
the legend boxes on p10, p11, p20, p49, p50), the label is used verbatim as the canonical
name. Do not invent new names: if you meet an icon that is not in this table, use the
closest generic entry and leave a `<!-- ? unidentified icon -->` comment rather than
guessing.

Page references are **PDF page numbers** (printed page = PDF page − 4).

## Notes on usage

### Ability checks

Two shapes, distinguished by **box colour and word order** (p10, p11):

* **Active check** — the ability symbol comes *first*, then the target number in a **red**
  box. Transcribe `[Agility] 6`. Rolled with `[Action Die]`.
* **Reactive check** — the target number comes *first*, in a **blue** box, then the
  ability symbol. Transcribe `4 [Might]`. Rolled with `[Reaction Die]`.

A reactive check is normally preceded by what it is reducing, so the full inline form is
`[Damage] 4 [Might]` or `[Stamina] 3 [Will]` (p11, p18, p34).

If a check may be made with more than one ability, the symbols are separated by a pipe:
`[Might] | [Agility] 5` (p10).

Outcome clauses follow the check; keep the book's own punctuation:
`[Agility] 6 Success » FLIP`, `[Will] 5 Fail » [Held]` (p26, p30).

Modifiers use the standalone symbols, never the die faces: `+2 [Success]`, `-1 [Success]`,
`+1 [Shield]`.

### Red and blue number boxes — a disambiguation rule

A red or blue rounded box holding a number is **either** a check target **or** a count of
dice. Decide from what sits next to it:

| What you see | Meaning | Transcribe |
| --- | --- | --- |
| ability symbol, then red box `6` | active check, difficulty 6 | `[Agility] 6` |
| blue box `4`, then ability symbol | reactive check, difficulty 4 | `4 [Might]` |
| red box `3` alone (after "using", "+", "roll") | 3 Action dice | `3 [Action Die]` |
| blue box `2` alone | 2 Reaction dice | `2 [Reaction Die]` |

So p38's "Make a melee attack using 2 ▮" is `Make a melee attack using 2 [Action Die]`,
and the matching card line `[Melee Attack] + 3` is `[Melee Attack] + 3 [Action Die]`.

### Die faces

Write a die *face* only where the book means a specific rolled result; write the plain
`[Action Die]` / `[Reaction Die]` where it just means "a die":

* "roll 3 [Action Die]" — generic dice.
* "rerolling when you roll a [Action Die: Extra Roll]" — a specific face.
* "counting each [Action Die: Stamina] as 2 successes" — a specific face.
* "Each [Reaction Die: Reaction] you roll … may be used to reroll that die" — a face.

The four Action-die faces are `[Action Die: 1 Success]`, `[Action Die: 2 Successes]`,
`[Action Die: Extra Roll]`, `[Action Die: Stamina]`. The four Reaction-die faces are
`[Reaction Die: Blank]`, `[Reaction Die: 1 Shield]`, `[Reaction Die: 2 Shields]`,
`[Reaction Die: Reaction]`.

**The dark-box convention** (stated on p49): a die face drawn *inside a dark box* means
"you may use each die showing that symbol for this special effect". Transcribe the face
normally — the dark box needs no separate notation, but the sentence around it will
usually say "each … you roll may be used to …".

### Numbers attached to icons

Put the number where the book puts it, and add no punctuation:

* number **before**: `2 [Damage]`, `1 [Stamina]`, `+1 [Damage]`, `-1 [Success]`,
  `3 [Action Die]`.
* number **inside or after**: `[Movement Point] 2`, `[Range] 0-1`, `[Area] 3`,
  `[Hand] 1`, `[Heal] 5`, `[Restore Stamina] 5`, `[Lock Stamina] 2`,
  `[Encumbrance] 2`.
* Enemy health equations use `[Hero Count]`: `3 [Hero Count] +5`.

### Initiative

Initiative encodes **shape = who** and **colour = when**: a black disc with a coloured
glyph is an Ally/Hero, a coloured plaque with a skull is an Enemy; red = Fast, blue =
Medium, green = Slow (p20, p68). Always name both halves, e.g. `[Ally Medium]`.
`[First]`, `[Last]` and `[Ally]` are the three *special* initiative tokens (p33) and are
separate from the Fast/Medium/Slow set.

### Conditions

There are exactly ten conditions (p62, p68), numbered 1–10. All ten share the same
pentagonal silhouette and differ only in colour and inner motif, so **an inline condition
icon cannot be read from its pixels**. Infer the name from the surrounding sentence — the
book almost always names the condition in prose beside the icon. If the sentence really
does not say, transcribe `[Condition]` and leave a `<!-- ? -->` comment.

`[Condition]` (the pentagon with a question mark) is a distinct icon in its own right: the
generic "a condition is applied" marker, not any specific condition.

Seven conditions exist as both cards and tokens (Bleeding, Confused, Dominated, Held,
Slowed, Stunned, Weakened); three are cards only (Blessed, Cursed, Invisible).

### Keywords are words, not icons

Many card effects that look symbolic are set as **typeset word tags** and should be
transcribed as plain text, not bracketed: *Pierce N*, *Evade N*, *Riposte N*, *Drain N*,
*Push·N*, *Pull·N*, *Jump·N*, *Cleave*, *Mirror*, *Overkill*, *Taunt N*, *Light*,
*Climb*, *Illegal*, *Non-Elite*, *Once / Twice per scenario*, *Remove Wounded*,
*Remove Exhausted*, *Lock picking*, *Herbalism*, *1/turn*, *1/Overkill*, *Shuffle*.
The `»` between two attack blocks ("and then another attack") is likewise literal text.

### Elements, professions and classes

The rulebook does **not** define elemental damage symbols. "Elemental Jade", "Nature
Essence", "Death Essence", "Magic Essence", "Life Essence", "Agura Crystal", "Blood
Crystal" and "Lanium Bar" are *Item token* names printed as plain text (p45, p59, p60).
Professions and Classes are named in text too. Do not invent `[Fire]`/`[Nature]`-style
notations.

### Hero tokens

Each Hero has a family of coloured round marker tokens (Drenosh dark red, Jonai bronze,
Lunara cream-gold, Matajam green, Torrax purple, Venia slate-blue, Zuva'Sai cyan), named
individually on p68 and used on p38–p44 — e.g. Curse of Blood, Fiery Weapon, Fire Trap,
Wall of Fire, Jinx, Stone Form, Metamorphose. Transcribe these by their printed name plus
the word "token" (e.g. "the Fiery Weapon token"), not as bracketed icons.

### Item token values

Item token *shape* encodes sale value (p13, p68): small circle = 1 [Star], triangle =
3 [Star], pentagon = 5 [Star], large circle = 10 [Star], octagon = 20 [Star]. This is a
property of the physical token, not an inline icon.

### Things that are pictures, not icons

Component photographs, card-anatomy diagrams, card backs, map extracts and decorative
chapter art are illustrations. Give them a short italic caption or a Markdown image
placeholder; do not give them bracket notation.
