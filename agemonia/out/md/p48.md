##### Item Requirements (p44)

Some Item cards have requirements (shown on the left hand side) that must be met in order for your Hero to be able to use them.

| Requirement | Description |
| --- | --- |
| [Hand] 2 | The item must be an active item. The number after the hand symbol shows how many hands the item requires. |
| [Lock Stamina] 1 | The item must have stamina locked on it (see Locking Stamina on p. 29). |
| [Might] 2 | Your Hero must have at least the value shown in the given ability. |

##### Item Card Limits (p44)

You may use at most one of each of the following items at a time:

- 1 helmet (an armor with "Helmet" or "Helm" in its name)
- 1 non-helmet armor or robe
- 1 backpack
- 1 pet

You may take others with you during a scenario. If you do, place them underneath the item of the same type that you are using with just their name and encumbrance showing.

> **Sidebar — Example:** *This Hero is currently using their Luawa pet Item card. If they wish to use their Gric pet Item card, they must spend a maneuver to swap them over.*

If you wish to start using one of these items, spend a maneuver and place the item you now wish to use above the item you are no longer using, arranging them in a similar manner as before. If the item requires stamina to be locked on it to use, you must do so immediately. See Locking Stamina on p. 29.

If you are using an item of one of these types and you gain another during a scenario, place the new item underneath the item you are using in a similar manner to before. You may start using this new item by spending a maneuver as above.

If you gain an item of one of these types, but are not currently using another one of the same type, place the new item sideways in your backpack. You may start using this new item by spending a maneuver as above. If you do so, rotate it upright to show you are now using it.

##### Heavy Armor (p44)

Heavy Armor is any Armor Item card that requires stamina to be locked on it to use.
