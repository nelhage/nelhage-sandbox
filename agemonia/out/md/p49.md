#### Common Item Card Effects (p45)

| Effect | Description |
| --- | --- |
| [Discard] : | You must discard the item to use it. |
| [Maneuver] | You must spend a maneuver to use the item. |
| [Range] 0-1 / [Range] 1-2 | The range the effect may be used at. |
| [Area] 2 | For effects that affect Allies, apply the effect to all Allies within range of the Hero using the item.<br>For effects that affect Enemies (such as attacks), apply the effect to all Enemies within range of a chosen area. If no range is given, the chosen area is the one containing your Hero. |
| **Illegal** | The item is illegal (see Illegal Items on p. 10). |
| **Lock picking / Light / Herbalism** | These phrases may allow you to choose a special option or give you a bonus an an ability check. |
| +2 [Success] | Gain a number of extra successes on an attack or effect. |
| + [Action Die] 2 | Roll the extra number of [Action Die] shown. |
| + [Reaction Die] 2 | Roll the extra number of [Reaction Die] shown. |
| +2 [Encumbrance] | Increase your encumbrance limit by the amount shown. |
| [Restore Stamina] 5 | Restore the amount of spent stamina shown. |
| [Heal] 5 | Heal the amount of damage shown. |
| [Restore Stamina] / [Heal] 8 | Restore spent stamina and Heal damage in any combination up to the total amount shown. |
| **Remove Wounded** | Remove wounded status from a Hero (see Removing Wounded Status on p. 24). |
| **Remove Exhausted** | Remove exhausted status from a Hero (see Removing Exhausted Status on p. 24). |
| **Jump•2** | Jump the amount shown (see Jump on p. 29). |
| **Evade•2** | Gain the amount of Evade shown this turn (see Evade on p. 29). |
| [Might] +2 / [Agility] +2 / [Will] +2 | Increase the relevant ability level by 2 until the end of this round. If used during the City or Journey step, increase the relevant ability level by 2 for one active or reactive ability check. |
| **Defeat (Aox) (Non-Elite)** | An effect may show one or more qualifiers in brackets according to the type of Enemy it can affect.<br>For example: “(Aox)” means it only affects Aox Enemies, and “(Non-Elite)" means it does not affect Elite Enemies. |
| **Once / Twice per scenario** | The effect may be used the stated number of times during each scenario. Each time you use the effect, place a Cross marker on the Item card to remind you. Remove the Cross marker at the end of the scenario. |
| [Action Die: Stamina] +2 [Success]<br>[Might] [Reaction Die: Reaction] +1 [Shield] | The symbol side of an Action or Reaction die surrounded in a dark box signifies you may use each die showing that symbol for a special effect. If you do, you may not use the die for any other purpose, such as spending up to 2 stamina to gain successes. |
